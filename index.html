Browser flashing · Web Serial

Reflash over USB, in the browser

Writes the complete bootable image — bootloader, partition table, NVS, application and OTA data — at the vendor's own offsets. Nothing to install, nothing uploaded.

This erases the device. A full reflash wipes every setting. On U1 and U2 that includes the CD KEY — copy it from Settings → System in the miner web UI first, because once lost it cannot be recovered from the firmware. S1 has no CD KEY, so there is nothing to save.

Only need to update a device that already works? Use the OTA .zip from the firmware archive instead — it keeps your settings and, on U1/U2, the key.

Procedure

How to flash

Before you connect

  1. U1 / U2 only — back up the CD KEY. Web UI → Settings → System. A full erase removes it. S1 has no key.
  2. Use desktop Chrome or Edge. Web Serial is not available in Safari, Firefox or on mobile.
  3. Use a data-capable USB cable. Charge-only cables are the most common failure.
  4. Hold BOOT while plugging in if the board is unresponsive — this forces download mode.

Flashing

  1. Click the button for your board above.
  2. Pick the serial port that appears (usually CP210x or CH34x).
  3. Keep Erase device checked for a clean install.
  4. Wait for Installation complete — do not unplug during the write.
  5. After reboot, join the device AP and open the web UI. On U1/U2, re-enter your CD KEY there.
Troubleshooting. No port shown: install the CP210x / CH34x driver, or try another cable and port. Flash fails at “Connecting”: hold BOOT while reconnecting. Board boots but shows nothing: the wrong image was written — S1, U1 and U2 images are not interchangeable.
